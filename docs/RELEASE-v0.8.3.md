# 栖页 · Lattira v0.8.3

修正资源库「详细信息」列表的列边界、文字对齐和位置行高。

- 仅前四列保留宽度调整手柄；最后的「所在位置」列填满剩余宽度，右边界固定在表格最右侧。窄窗口保留最小宽度和横向滚动，旧版保存的位置列宽不再影响布局。
- 名称、导入时间、类型、大小恢复一致的垂直居中对齐。
- 每个引用位置直接显示为一行，几个位置就是几行；每行高度固定，长路径以省略号结尾，悬停可查看完整路径。没有位置的文件保留一行。
- 每行位置可直接点击，继续支持任意层文件夹及同一文件的不同引用卡片。虚拟列表按实际位置数量计算高度，大量文件滚动和筛选仍保持正确。

验证：浏览器实测四列拖动、最后一列边界、刷新保留及旧偏好兼容、键盘调整、Esc 回退、快捷搜索、窗口变化和窄窗口滚动；1～4 个位置行高、文本对齐和省略号；40 层路径跳转、同画布重新定位、跨画布及根目录定位；1001 个资源的不同高度虚拟列表、滚动到底及筛选。28 项前端回归测试、类型检查、474 条翻译检查和生产构建通过。

Windows x64 安装包包含在线更新签名，附带 `latest.json` 更新清单。
