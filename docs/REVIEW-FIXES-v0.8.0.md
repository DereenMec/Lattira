# v0.8.0 代码审视修复记录

对应本轮审视的 36 项问题。下表列出最终实现位置及行为，便于逐项复查。

| # | 问题 | 修复后的行为与主要实现 |
| --- | --- | --- |
| 1 | 保存失败吞掉异常、草稿被误判已保存 | `canvasStore` 保留 dirty 状态并传播失败；提供重试和另存恢复副本。 |
| 2 | 长文本编辑窗口草稿未参与退出保存 | 文本编辑器注册提交回调；`flush` 先提交所有编辑器草稿。 |
| 3 | 托盘退出超时强制关闭、失败仍退出、普通关闭不保存 | 删除强制退出计时；关闭与托盘退出统一等待保存，失败取消退出并显示主窗口。更新安装前也再次保存。 |
| 4 | 删除画布先移动文件再保存 | `appStore.deleteCanvas` 先等待保存，再执行删除。 |
| 5 | 切换工作区后再保存、跨工作区缓存串用 | 原工作区先保存；切换时重置缓存与异步任务，工作区路径驱动视图重新挂载，兼容相同画布 ID。 |
| 6 | 异步导入、粘贴、新建落到后来的画布或文件夹 | `operationTarget` 绑定工作区、画布、代次和目标文件夹；返回时检查目标是否仍有效。 |
| 7 | 改名依据过期引用数，影响其他画布 | 卡片改名始终创建独立文件；资源库操作先保存并刷新引用，操作后重新加载受影响画布。 |
| 8 | 同一资源重复导入时改名同时改变原卡片 | 重名卡片分配新的资源 ID，原卡片继续引用原文件。 |
| 9 | 回收站引用被清理、资源编辑改变历史画布 | 删除时创建隐藏的独立资源快照，引用计数保护回收站文件；旧工作区打开时迁移仍可读取的资源。浏览器预览也使用独立快照。 |
| 10 | 恢复同内容资源合并 ID，破坏引用 | 恢复保留原 ID，同内容记录用附带 ID 的指纹区分。 |
| 11 | 文件与 SQLite 修改不一致、临时文件不安全 | `journal` 为文件操作记录持久化撤销日志；SQL 提交标记决定启动恢复时回滚或保留。写盘使用唯一临时文件和同步落盘；改名、删除时无法更新引用画布则整体回滚。 |
| 12 | 外部编辑被旧缓存或自动保存覆盖 | 载入比较内容指纹；保存校验预期指纹，冲突时保留外部文件并另存本地草稿。 |
| 13 | 去重复用已经丢失的文件 | 复用前检查实体文件，丢失时重新导入。复制登记使用实际目标文件的内容指纹。 |
| 14 | 只检查导入最外层重名 | `resolveIncoming` 检查每一层文件夹的兄弟项。 |
| 15 | 前后端名称清理规则不同 | 项目、画布、文件和文件夹使用一致的 Windows 非法字符、保留名及长度规则；校验清理后的名称。 |
| 16 | 命名计划提前修改资源、取消解散仍产生副作用、撤销丢失文件名 | 先收集全部选择，再复制文件并应用计划；取消解散不执行计划；改名通过资源 ID 补丁进入历史。 |
| 17 | JSON Canvas 自定义颜色、箭头与未知字段丢失 | 保留原始节点、连线、根扩展字段；保存自定义颜色、两端箭头与连接边；渲染自定义色及箭头、标签、端点。 |
| 18 | 重叠分组互相成为父级导致不可见 | 以面积和稳定 ID 决定包含顺序，并清理断裂或循环父级。 |
| 19 | ID、文本、几何、视口与扩展字段校验不足 | 拒绝重复 ID、非法类型、非字符串内容、异常尺寸和视口、无效连线端点属性；保留合法小数尺寸。导入仅补齐缺少的默认字段。 |
| 20 | 画布包缺少网页预览图与图标 | 导出加入 `links/`，导入复制为内容指纹缓存并重写路径。 |
| 21 | 批量导入部分成功后失败，界面不显示已完成项 | 导入结束或失败后刷新资源和画布列表；后端在每个画布登记时同步索引。 |
| 22 | OCR 全局调度、失败永久空结果、旧结果覆盖新文件 | 按工作区独立调度；失败保持待识别并退避重试；写入核对指纹、修改时间和路径，外部文件变化重置重试状态。 |
| 23 | 修改 URL 后被旧预览请求阻塞 | 请求按工作区、画布、卡片和 URL/令牌管理；新 URL 可立即获取，旧结果不会应用。 |
| 24 | 同 URL 图片更新仍命中旧缓存 | 网页图片按实际内容指纹命名，而非仅按 URL 命名。 |
| 25 | 无扩展名文件改名添加“.未命名” | 空扩展名保持为空。 |
| 26 | 连线反向不计入变化 | 比较连线完整内容，反向进入编辑统计；同时交换连接边。 |
| 27 | 搜索全表扫描、结果静默截断 | 建立 FTS5 trigram 索引；每页 50 条并提供加载更多。少于 3 个字符时保留 LIKE 回退，以保证短词查询完整。 |
| 28 | 平移缩放保存重复重建内容索引 | 分开记录视口与内容 dirty；仅视口变化传入空索引更新。 |
| 29 | 屏外连线仍渲染、拖动重建节点 Map | 依据视口裁剪连线，复用并增量维护节点查找表。 |
| 30 | 资源和文件夹全部挂载、原图解码、缩小仍加载图片 | 固定行高虚拟化资源网格、表格和文件夹；Windows 生成 512 像素内容缓存缩略图，最多并发 3 个请求；低细节模式跳过图片。 |
| 31 | 大文件操作长时间持锁、IPC 整文件转数值数组、缓存历史无上限 | 导入哈希/复制与导出压缩在锁外执行；剪贴板文件按 256 KiB 分块传输；后台画布缓存最多 6 个，历史同时限制条数与元素引用预算。 |
| 32 | 输入法 Enter 被当作确认操作 | 文本编辑、重命名、搜索及全局键盘处理检查 composing 状态。 |
| 33 | 子菜单无法键盘操作、弹窗焦点逃逸、全局快捷键穿透 | 右键菜单支持方向键和子菜单返回；弹窗循环焦点、关闭后恢复焦点，任意控件上的 Esc 均可关闭；全局操作跳过弹窗。 |
| 34 | 多个重命名弹窗覆盖，Promise 无法结束 | 提示框使用 FIFO 队列，关闭校验当前实例，切换工作区取消并完成全部等待者。 |
| 35 | 资源卡片内嵌按钮结构非法 | 外层使用可聚焦容器，位置按钮独立交互，避免嵌套 button。 |
| 36 | 浏览器文件刷新丢失、配额错误静默、命名和恢复搜索不一致 | 文件本体保存到 IndexedDB；元数据写入失败传播并回滚；名称与桌面一致，导入与恢复立即重建索引，文件搜索返回资源 ID；更新预览说明。 |

## 验证

- `npm test`：22 项通过，执行实际 TypeScript 模块，覆盖保存失败与并发、命名计划、格式兼容、异步目标失效、过期链接预览、浏览器文件保存及恢复。
- `cargo test --manifest-path src-tauri/Cargo.toml`：37 项通过、4 项原有测试跳过。包含注入失败回滚、模拟中断后重新打开、外部修改冲突、回收站快照、同内容恢复、完整搜索分页、OCR 重试和过期结果、画布包预览图往返，以及 Windows 解码生成 PNG 缩略图。
- `npm run build`、`npm run i18n:check`、`cargo fmt --manifest-path src-tauri/Cargo.toml --check`、`git diff --check` 通过；470 条界面文字无缺失翻译。
- 浏览器交互检查：编辑草稿切页后仍保留并可搜索；搜索弹窗 Tab 循环及结果按钮 Esc；右键子菜单方向键进入/返回；文件导入、刷新后下载，SHA-256 与原文件一致；151 个资源初始挂载 55 张卡片、末尾 31 张，详情表格挂载 31 行；500 项文件夹初始挂载 40 项、末尾 24 项，末项可见；控制台无警告或错误。

验证边界：四项跳过测试分别涉及系统剪贴板、外部 OCR 样例、真实网页请求和本机 ShellNew 注册表输出。未执行真实用户工作区的退出/更新安装演练，也未将新的端到端帧率数字替换为已有性能基准。构建仍有 Vite 单个主包超过 500 kB 的体积提示，不影响构建通过。
