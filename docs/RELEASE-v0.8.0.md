# 栖页 · Lattira v0.8.0

本次修复代码审视发现的 36 项功能、性能、可靠性和易用性问题。

- **保存与退出**：保存失败保留草稿、支持重试和恢复副本；切换画布、删除、切换工作区、退出和安装更新前统一提交文本编辑并等待保存。外部修改的画布不会被旧缓存覆盖。
- **文件与回收站**：卡片改名使用独立副本，正确处理同一文件重复导入和嵌套文件夹重名；命名与 Windows 清理规则一致。回收站画布使用独立资源快照，恢复保留文件 ID。文件操作与数据库加入持久化回滚和启动恢复。
- **导入与格式兼容**：异步任务绑定原工作区、画布和目标文件夹；导入失败后刷新已完成结果。JSON Canvas 保留自定义颜色、连线方向、端点和未知字段，校验异常数据并避免重叠分组互相隐藏。画布包包含网页预览图和图标。
- **搜索与图片识别**：搜索使用 trigram 全文索引并提供加载更多；仅视口变化时不重建内容索引。OCR 按工作区调度，失败退避重试，并丢弃过期结果。网页预览刷新使用内容指纹缓存。
- **大画布与资源库**：连线视口裁剪、资源库和文件夹列表虚拟化、图片缩略图缓存与并发限制；缩小时跳过图片解码。大文件复制和压缩移出工作区锁，剪贴板文件分块传输，限制历史记录和画布缓存占用。
- **键盘与浏览器预览**：修复输入法确认误提交、弹窗焦点和快捷键隔离、右键子菜单键盘导航、重命名弹窗并发覆盖及资源位置按钮结构。预览模式用 IndexedDB 保存文件，刷新后仍可读取，并显式报告存储失败。

验证：22 项前端回归测试、37 项后端测试通过，类型检查、生产构建和 470 条翻译检查通过。另完成浏览器草稿切页保存、搜索、弹窗焦点、菜单键盘导航及文件导入刷新下载校验。四项原有依赖剪贴板、样例图像、联网或本机注册表输出的测试保持跳过。

Windows x64 安装包包含在线更新签名，附带 `latest.json` 更新清单。
