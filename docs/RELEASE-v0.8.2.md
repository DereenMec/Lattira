# 栖页 · Lattira v0.8.2

资源库的「详细信息」列表现在支持调整所有列的宽度。

- 拖动列标题右边的分隔线即可调整该列，不会误触排序或清除已选文件。列宽独立变化，宽于窗口时可以横向滚动。
- 松手后记住列宽，重新打开资源库或重启应用仍然保留。双击分隔线恢复该列的默认宽度。
- 分隔线支持键盘操作：左右方向键每次调整 10 像素，Shift 加方向键每次调整 50 像素；拖动时按 Esc 可取消本次调整。获得焦点后仍可使用 Ctrl+E 搜索。
- 每列设有最小宽度，防止标题和操作入口被压没；无效偏好自动恢复，存储不可用时仍可正常调整本次界面的列宽。

验证：浏览器实测五列独立拖动、刷新保留、排序和选择隔离、双击重置、键盘调整、最小宽度、窄窗口滚动、指针取消、视图切换清理、Esc 回退及存储异常恢复。完整路径和深层跳转回归、251 个资源的虚拟列表检查均通过；26 项前端回归测试、类型检查、474 条翻译检查和生产构建通过。
